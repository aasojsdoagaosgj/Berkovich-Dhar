## 3. 主位相と、転換付近の精度

### 法3

Euler–Maclaurin のシフト $1/3,2/3$ に対して

```math
B_1(1/3)=-1/6,\quad B_1(2/3)=1/6,\quad
B_2(1/3)=B_2(2/3)=-1/18,\quad
B_3(1/3)=-B_3(2/3)=1/27
```

を代入すると、4乗の $h,b,d$ は記載式と一致する。したがって対数段階での $s/4$ 倍は正当である。位相

```math
\phi_s(\tau)=-\frac{s\pi}{18}+
\frac{s}{3}\arctan\frac{\sqrt3 e^{-\tau}}{2+e^{-\tau}}
```

の導関数は負で、対象4冪では剰余2の振幅に唯一の単純零点がある。条件 $\phi_s=-\pi/6$ を解くと (M1) の式になる。

Gaussian 展開の一次補正

```math
A_1=b\Psi-\frac{\Psi''}{2g}
+\frac{H'''\Psi'}{2g^2}
+\Psi\left(\frac{H''''}{8g^2}-\frac{5(H''')^2}{24g^3}\right)
```

は、虚方向の Taylor 展開から独立に一致した。特に $H'''\Psi'$ の符号は正である。二次補正 (C7a) の次数条件・Gaussian moments・二根で反転する $d$ の項も一致する。

### 法5

(P1) の確認には、四項の和を直接扱った。原稿の $U,V$ に対して

```math
\lambda_1=i(U+V),\qquad \lambda_2=i(U-V),\qquad
\lambda_4=-\lambda_1,\qquad\lambda_3=-\lambda_2
```

が実軸上で成立する。よって

```math
\Psi_{s,a}
=2\cos\left(s(U+V)-\frac{2\pi a}{5}\right)
+2\cos\left(s(U-V)-\frac{4\pi a}{5}\right)
```

から

```math
\Psi_{s,a}=4\cos\left(sU-\frac{3\pi a}{5}\right)
\cos\left(sV+\frac{\pi a}{5}\right)
```

が正確に出る。$U,V$ の単調性と角度範囲を追うと、剰余0・1・2の符号、剰余3・4の唯一の単純零点、(P2) の方程式はいずれも正しい。

法5の一次補正 $b_h$ は根ごとに異なるが、本文はこれを共通定数にしていない。$A_1=B_a+\mathcal S_1\Psi$ として合成する (P5) の取り扱いは正しい。

### 誤差の微分は不要

両法とも、固定した複素近傍での解析性と正の曲率下界により、正規化係数について

```math
\frac{c_j}{B_{n,j}}=\Psi(\tau)+\frac{A_1(\tau)}n+
\frac{A_2(\tau)}{n^2}+O(n^{-3})
```

が一様に得られる。Gaussian 変数で $n^{-1/2}$ の5次まで展開し、奇数次を対称積分で消す手順で、必要な剰余次数が確保されている。

同一剰余で次数を $p$ 増やすと

```math
\Delta\tau=-\frac{1}{n^2H''(\tau)}+O(n^{-4}).
```

二つの値の展開を引くため、未知の剰余は $O(n^{-3})$ のままである。一方、主差は

```math
\Delta\left(\frac{c_j}{B_{n,j}}\right)
=-\frac{\Psi'(\tau)}{n^2H''(\tau)}+O(n^{-3}).
```

零点近傍では $\Psi'>0$ に共通下界があるので、十分大きい $n$ で厳密に減少する。未知の $O$-項を微分する仮定は不要であり、転換付近で正負が繰り返す余地を除けている。正規化因子は正なので、符号判定を保存する。

さらに零点における一次補正から

```math
\beta=\frac{H''(\tau_*)A_1(\tau_*)}{\Psi'(\tau_*)}
```

が得られる。法3ではこれが (M4) に簡約される。$j=pk+a$ による変換が影響するのは定数項であり、係数 $p$ の落としはない。

## 4. 最も繊細な端点：法5の3乗

$a=2,4$ では無限積の係数が恒等的に零なので、係数積分の全円周で

```math
[q^j]P^3=[q^j]\{G^3(T_n^3-1)\}
```

を使える。(E4) は実際にこの形で使用されている。

eta 変換後の誤差を

```math
(U_h^3-1)(T_n^3-1)
```

のまま評価することにより、$x=e^{-\tau}$ が失われない。主部分から引かれた $G^3$ は、同一の円弧パラメータにおいて

```math
\sum_{h=1}^4\zeta^{-ah}\kappa_h^3=0
```

で完全に消える。残る主項の因子 $e^{-z}$ は、次数を $d=j-5n$ へ移すことと厳密に対応する。

原稿の評価から、$x$ で割った後の dual error は

```math
\frac{C_*}{w_0}
\exp\left[-\frac{1-(6s/5)\operatorname{Li}_2(x)}{w_0}\right]
```

以下となる。ここで $w_0=\tau/(5n)$、$C_*$ は $n,\tau$ に依存しない定数である。$\tau\ge5$ では $\operatorname{Li}_2(x)\le1/139$ なので、指数損失は一様に正である。

補円弧についても損失は

```math
\frac{s}{w_0}\left(\frac1{25}-\frac65\operatorname{Li}_2(x)\right)
>\frac{s}{40w_0}
```

となる。$q=1$ 付近の円弧は別の eta 変換で扱われ、被覆から抜けていない。

弱い振幅を $x$ で割った量の端点値は、独立に計算すると

```math
\lim_{\tau\to\infty}\frac{\Psi_{3,2}(\tau)}{e^{-\tau}}
=-\frac32(1+\sqrt5),\qquad
\lim_{\tau\to\infty}\frac{\Psi_{3,4}(\tau)}{e^{-\tau}}
=\frac32(\sqrt5-1).
```

したがって、零へ近づく元の振幅に定数下界を要求する誤りはなく、必要な再正規化後の量に一様な符号余裕がある。

複素円板 $|z-\tau|\le\tau/4$ では、$|x|\le e^{-15/4}$、$|w|\le5w_0/4$ であり、$E_h/x=O(w)$ と可除特異点の議論から振幅は一様に有界となる。Cauchy 評価によって変動は $O(|z-\tau|/\tau)$。また共役対称性により実軸上の振幅は実数である。

$N=n/\tau$、$y=\tau v/\sqrt N$ とすると、指数の三次誤差と振幅の変動はともに Gaussian 積分後 $O(N^{-1/2})$ になる。補円弧の最悪の前因子も

```math
O(N^{5/2}e^{-cN})
```

である。これは $n\sqrt{g_n}=O(N^{3/2})$ と $w_0^{-1}=5N$ の積であり、$N$ とは独立の $n$ の冪は残らない。$\tau$ が $\sqrt n$ 程度まで増大しても、一様評価は保たれる。

## 5. 初期次数・最初の尾部・全係数への接続

### 無限積と2000次の切断

[Wang, Theorem 1.1](https://arxiv.org/html/2108.03932v3) を原典で照合した。素数への代入、適用条件、Dedekind 和、Bessel 項、明示誤差は原稿と一致する。$j$ に追加の互いに素条件はない。主項が消える剰余は Jacobi 恒等式によって別途処理されている。

原稿の記号で $d=j-\mu$ とすると、非零主項の下界 $e^X/(300d^{3/4})$ と誤差上界 $5e^{X/2}+10^{18}$ は正当である。誤差比に現れる関数について

```math
\frac{d}{dd}\log\left(d^{3/4}e^{-a\sqrt d}\right)
=\frac{3}{4d}-\frac{a}{2\sqrt d}<0
```

が $a=7/10,7/5$、$d\ge2000$ で成り立つため、切断点以後の単調性も成立する。$j\ge2001$ なら $d>2000$ なので、厳密整数検査 $j\le2000$ と隙間なく接続する。

初期符号は次のとおりである。

| 法・冪 | 剰余順の符号 | 零 |
|---|---|---|
| 法3、5–8乗 | $+, -, +$ | なし |
| 法5、2乗 | $+, -, -, +, +$ | 次数9のみ |
| 法5、3乗 | $+, -, 0, +, 0$ | 剰余2・4が恒等的に零 |

有限積の最初の省略因子は次数 $pn+1$ なので、次数 $pn$ までの一致は厳密である。

### 法5・3乗の最初の尾部

(F2) の反復では残項の最低次数が無限大へ進む。(F3) の対称化では、$j<k$ の組の分子が

```math
Q^{j^2+k^2+2j}(1-Q^{k-j})^2
```

となり、外側および積の分母にある二つの $1-Q$ が正確に消える。したがって $0\le D\le h^2$ は係数ごとの不等式である。

(F4)–(F6) も独立に展開して一致した。特に $(1-Q)^2$ の負の係数を無視しておらず、$J_4\ge2gh^5$、および $-J_2$ の全次数での厳密正性が従う。これらを用いる (F7) は、主張された $0\le K\le n-1$ で正しい。

剰余2・4の最初の尾部の末端はそれぞれ $10n-3$、$10n-1$。次に必要な次数は $10n+2$、$10n+4$ であり、端点評価の $j\ge10n$ に入る。

### 共通閾値と相反性

法3の端点では

```math
\tau^2<10n,\qquad N>\sqrt{n/10},
```

法5では

```math
\tau^2<4n,\qquad N>\sqrt n/2.
```

このため端点での誤差収束は、各範囲の全係数に一様である。法3の内部との重なりは $-H'(6)>-H'(7)$、法5は $-H'(5)>-H'(11/2)$ から出ており、$n^2$ の尺度で正の幅を持つ。整数丸めで隙間は生じない。

下半分をすべて処理した後、因子数が偶数であることから $c_j=c_{D-j}$ を使える。法5・3乗の剰余3では、下半分の剰余2の初期零が末尾の零へ反射する。そのため「最後の非負係数」は転換点の適切な定義ではないが、本文は「最初の負係数の直前」を採用しており、整合している。

必要な一次文献は閲覧できた。法3の基底積評価は [Wang–Krattenthaler, Lemmas 9.2, 9.4](https://arxiv.org/pdf/2201.12415)、無限積入力と5分解は [Wang, Theorem 1.1 および Proposition 3.6](https://arxiv.org/html/2108.03932v3)、変換式は [DLMF 23.18](https://dlmf.nist.gov/23.18#E5) と対応を確認した。今回必要な引用結果に、文献へアクセスできず未確認のまま残したものはない。
